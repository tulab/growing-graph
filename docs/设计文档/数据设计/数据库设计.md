# 设计文档 · 数据库设计

## 1. 存储总览

| 层 | 存储 | 内容 |
|---|---|---|
| graph | SQLite | 图谱元数据、归属用户（user_id）、维度变量声明 |
| schema | SQLite | 类型字典（按 graph 分区，property 绑定 object_type） |
| transaction | SQLite | 操作记录（每次写调用） |
| instance | SQLite | 图实例（object / link，按 graph 分区） |

单文件 SQLite 承载全部数据，无外部数据库依赖。

## 2. 表结构

### 2.1 graph（图谱）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| user_id | text | 归属用户（无 user 表、无外键；graph 操作校验归属） |
| name | text | 图谱名 |
| description | text | 图谱描述 |
| dims | json | 结构化维度字典：`[{key, label, values:[{code, label}]}]`（创建后不可修改） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 最近更新时间 |

- graph 是 schema 与 instance 的隔离边界（按 graph_id 分区）。
- 基于 graph 表校验归属：`graph.user_id` 记录所属用户，graph / schema / instance 操作前比对；无独立 user 表，身份由请求头 `X-Identity`（base64(JSON)，含 user_id / agent_id）注入，缺失即 401。

### 2.3 schema 类型表（object_type / link_type / property_type）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| graph_id | fk → graph | 所属图谱 |
| type | text | 类型码 |
| name | text | 类型名 |
| description | text | 描述 |
| dim | json | 按 graph.dims 变量写入的具体维度值 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 最近更新时间 |

- `(graph_id, type)` 唯一；名称与 id 在 graph 内唯一。
- `link_type` 的 `dim` 声明两端指向（source_level / target_level），供展示与应用层校验；引擎不强制（不做 dim 推断）。
- `property_type` 另含：
  - `object_type_id`：绑定到具体对象类型（该对象类型允许哪些属性键）；
  - `value_type`：值类型。
  - 唯一约束 `(graph_id, object_type_id, type)`——不同对象类型可各自定义同名属性键。

### 2.4 operation（操作记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| graph_id | fk → graph | 作用图谱 |
| user_id | text | 归属用户（无 user 表） |
| layer | text | 操作所在层（graph / schema / instance） |
| action | text | 对象与动作（`resource.action`，如 `object.create`、`link.delete`） |
| payload | json | 请求体 |
| created_at | datetime | |

- 每次写调用落一条，读调用不记录；供审计与回溯。

### 2.5 object（节点实例）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| graph_id | fk → graph | 所属图谱（分区边界） |
| type | text | 对象类型码 |
| title | text | 标题（顶层通用字段） |
| content | text | 内容 |
| property | json | 属性 Map：property_type.type → value |
| dim | json | 维度 Map：graph.dims 变量 → value（由调用方显式传入，不做推断） |
| business_key | text | 业务键（可空；upsert 端点已移除，当前无调用方） |
| created_at / updated_at | datetime | |

### 2.6 link（关系实例）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 主键 |
| graph_id | fk → graph | 所属图谱 |
| type | text | 关系类型码 |
| source / target | uuid | 端点节点 id |
| property | json | 关系属性（自由键） |
| created_at / updated_at | datetime | |

## 3. 隔离与路由

- 实例天然处于所属 graph 分区内（`graph_id` 列），不冗余 graph / user 字段，cypher / 查询不传 db / userid。
- 索引：object 按 (graph_id, type)、(graph_id, business_key)；link 按 (graph_id, type/source/target)。
- **schema 演化语义**：动态 schema 服务于知识重组而非全量重写；修改 schema 的 property 视为需重新调整所有受影响节点。
