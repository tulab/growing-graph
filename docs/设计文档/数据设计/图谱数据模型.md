# 设计文档 · 图谱数据模型

> 图谱数据分四层：**graph**（图谱边界）、**schema**（类型字典）、**instance**（实例数据）、**transaction**（操作记录）。
> 本页只记录功能分层；库表设计另见数据库设计文档。

## 1. 分层总览

| 层 | 组成 | 含义 | 存储 |
|---|---|---|---|
| graph | graph | 数据隔离边界、归属用户 | SQLite |
| schema | object_type · link_type · property_type | 能建什么类型 | SQLite |
| instance | object · link · property | 实际建了什么 | SQLite（按 graph 分区） |
| transaction | operation | 图谱操作历史 | SQLite |

## 2. 各层组成

### 图谱层（graph）

- 一个 graph = 一个图谱，`user_id` 记录归属用户（无 user 表；graph 操作校验归属），一个归属可对应多个 graph。
- 是 schema 与 instance 的隔离边界：类型字典与实例数据均按 graph 分区。
- graph 可声明一组维度字典（dims：`[{key, label, values:[{code, label}]}]`），供其 schema 元素与实例标注使用，并经接口下发。

### 结构层（Schema）

| 组成 | 说明 |
|---|---|
| object_type | 节点 / 对象类型定义 |
| link_type | 关系类型定义（dim 声明两端指向，供展示与应用层校验，引擎不强制） |
| property_type | 属性类型定义（绑定到具体 object_type，含值类型） |

- 三类元素名称与 id 在 graph 内唯一；类型按 graph 声明的维度变量取值标注。
- 属性类型与对象类型绑定：某对象类型允许哪些属性键由 property_type 决定，用于实例属性校验。

### 实例层（Instance）

| 组成 | 说明 |
|---|---|
| object | 节点实例：type、title、content、property、dim、created_at、updated_at |
| link | 关系实例：type、source、target、property、created_at、updated_at |
| property | 对象属性：object_id、type、value（挂在 object 的 property Map 上，非独立实体） |

- 数据按图谱分区隔离：实例的 `graph_id` 即隔离边界；graph 操作按 `graph.user_id` 校验归属，实例数据不冗余 user 字段。
- 实例 type 指向所属 graph 的类型字典，落在所属 graph 分区内。
- `property` 存属性 Map；`title` / `content` 为顶层通用字段，前端低级别视图隐藏 content。
- `dim` 由调用方显式传入——本系统只做基础设施，**不做 dim 推断**；维度的取值与语义由应用层定义并随 dim 传入。

### 事务层（transaction）

每次写调用落一条操作记录，供审计回溯；读调用不记录。

| 组成 | 说明 |
|---|---|
| operation | 操作记录：一次写调用 |
