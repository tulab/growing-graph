# 设计文档 · 技术选型

## 1. 选型

| 层 | 技术 | 版本 | 理由 |
|---|---|---|---|
| 语言/工具 | Python + uv | ≥3.11 / 0.11 | 环境隔离与依赖管理一体 |
| API | FastAPI | 0.115+ | Pydantic 校验 + 自动 OpenAPI 文档 |
| 存储 | **SQLite**（SQLAlchemy） | 2.0 | 单库内嵌免部署：图谱 / 类型字典 / 操作记录 / 实例一体，无外部依赖 |

## 2. 关键决策

| 决策 | 说明 |
|---|---|
| 统一用 SQLite 而非 MySQL / Neo4j | 单文件内嵌免外部依赖；图谱 / 类型字典 / 操作记录 / 实例一体承载，`SQLITE_URL` 可切其他 SQLAlchemy 方言 |
| 图算法用内存纯算 | 结构性查询（邻居/路径/子图/概览/连通/统计）加载整图到内存后经 BFS 完成；MVP 图规模小，负载可忽略 |

## 3. 配置（`app/config.py`，全部有默认值，可省略）

```
sqlite_url=sqlite:///./data/data.db     # 统一存储（SQLite，无需外部库）
cors_origins=                          # 留空默认放行全部 localhost 来源（任意端口）
```

## 4. 部署形态

- 单进程 uvicorn（`uv run uvicorn app.main:app --port 3003`）。
- 无容器 / 无外部服务依赖；数据落在 `data/data.db`。
