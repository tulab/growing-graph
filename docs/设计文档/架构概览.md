# 设计文档 · 架构概览

## 1. 总体架构

```
┌────────────────────────────── 后端（图引擎微服务） ──────────────────────────────┐
│  graph 包（app/graph/）· 自包含单包（无 core/modules 分层）                        │
│    config 配置 · db 存储引擎 · auth 身份解析 · errors 错误 · utils 工具            │
│    api 四层 RPC 路由（/api/graph|schema|instance|transaction）                    │
│    service 服务 + 校验 · stores 持久化 + 图算法 · models / schemas                │
│    统一约定：无 query 参数，一律 body 传参                                          │
└────────────────────────────────┬─────────────────────────────────────────────────┘
                                 │ SQLite：单文件库（无外部依赖）
                                 │  图谱 / 类型字典 / 操作记录 / 实例
                                 └─────────────────────────────────────────────────┘
```

## 2. 分层职责

| 层 | 职责 | 位置 |
|---|---|---|
| 后端 · graph | 图引擎单包：配置 / 存储引擎 / 身份解析 / 错误 / 校验 + 四层 api·service·stores | `app/graph/` |
| 存储 | 统一 SQLite：图谱 / 类型字典 / 操作记录 / 实例 | SQLite 单库 |

## 3. 模块划分（与代码对应）

```
app/
├─ main.py              装配入口：组装 graph 包 → CORS → 错误处理
└─ graph/               图引擎（自包含单包，无 core/modules 分层）
   ├─ api/              四层 RPC 路由（graph · schema · instance · transaction）
   ├─ service/          四层服务 + 校验 + 操作记录
   ├─ stores/           sqlite_store（统一持久化）· graph_store（图算法）
   ├─ models.py         ORM：graph / 类型三表 / operation / object / link
   ├─ schemas.py        请求 / 响应模型
   ├─ router.py         路由聚合
   ├─ config.py         配置（sqlite_url / CORS）
   ├─ db.py             SQLAlchemy Base + Database 引擎
   ├─ auth.py           请求身份解析：从 X-Identity 请求头读 user_id / agent_id（base64(JSON)，不内置鉴权，缺失即 401）；graph 操作按 graph.user_id 校验归属
   ├─ errors.py         5 位业务错误码 + 统一 handler
   └─ utils.py          id / 时间戳 / JSON 工具
```

## 4. 协作约定

- **后端为单一 graph 包**：无 core/modules 分层；config、存储引擎、错误、校验均收敛在 `app/graph/` 内，路由由 `main.py` 统一 `include_router`。
- **只提供 API，不托管前端**：本服务不返回坐标 / 展示数据，只返回图数据（含 dim）。
- **基础设施定位**：本系统不做 dim 推断，实例 `dim` 由调用方显式传入。
- **字典单一事实源**在应用层；应用层经写接口装配入库，后端不预置——维度字典经 `graph.dims` 下发，类型字典经 `/api/schema/types` 下发。
- **不预置**：启动不灌入任何业务内容；图谱 / 维度字典 / 类型字典 / 实例由应用层经写接口装配。基于 graph 表校验归属（graph.user_id 记录所属用户）；无独立 user 表，身份由请求头 `X-Identity` 注入（微服务场景由上游网关 / 调用方注入）。
