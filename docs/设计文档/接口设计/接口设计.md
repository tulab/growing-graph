# 设计文档 · 接口设计

> 依据《接口语义层次》《数据库设计》。RPC 结构 `/api/{layer}/{resource}/{action}`；JSON 传输。
> **统一约定：无 query 参数，一律 POST + body 传参**（全端点 POST，无 GET）。
> 查询/列表统一 `.../list`：body 带 `ids`——**`ids` 空/省略 = 返回全部（list all），`ids` 非空 = 仅返回这些元素的信息**；过滤字段（type/q/dim/source/target/…）与 ids 组合（AND）；实例节点 list 恒带 links 富化，传单 id 即详情（无独立详情端点）。
> 批量写接口统一 `{graph_id, items[]}`——**一次调用只操作一个图谱**：graph_id 在顶层，其余字段均作为 items[] 的子项，items 恒为数组；非批量单对象端点（insert/remove/attach/detach/property）仍为平铺字段。例外：`POST /api/graph/delete`（删除对象即图谱本身，允许一次跨图谱批量）。实例经 SQL 按 graph 分区（SQLite 承载）。错误统一见 §2。
> 身份：请求须带 `X-Identity` 头（值为 base64(JSON)，含 user_id，agent_id 可选），缺失或非法返回 20001；由上游网关 / 调用方注入。

## 1. 接口

### 1.1 graph（图谱操作）

#### POST /api/graph/list

图谱查询 / 列表：ids 空/省略 = 当前用户全部图谱；非空 = 仅这些图谱的元数据（未命中 / 无权访问的 id 被忽略）。

请求参数：

| 字段 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| ids | body | uuid[] | 否 | 空/省略 = 全部图谱；非空 = 仅这些图谱 id |

响应参数：

| 字段 | 类型 | 说明 |
|---|---|---|
| items | array | 图谱元数据列表 |
| items[].id | uuid | 图谱 id |
| items[].name | string | 图谱名 |
| items[].description | string | 图谱描述 |
| items[].owner_user_id | uuid | 归属用户 |
| items[].dims | array | 维度字典：`[{key, label, values:[{code, label}]}]` |
| items[].created_at | datetime | 创建时间 |
| items[].updated_at | datetime | 最近更新时间 |

#### POST /api/graph/create

创建图谱（当前用户所有）；dims 为维度字典声明，应用层据此装配图谱（创建后不可修改）。

请求参数：

| 字段 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| name | body | string | ✓ | 图谱名 |
| description | body | string | 否 | 图谱描述 |
| dims | body | array | 否 | 维度字典：`[{key, label, values:[{code, label}]}]` |

响应参数：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid | 新建图谱 id |
| name | string | 图谱名 |
| description | string | 图谱描述 |
| dims | array | 维度字典 |
| created_at | datetime | 创建时间 |

#### POST /api/graph/update

部分更新图谱元数据（仅 name / description；**dims 创建后不可修改**，update 传 dims 将被拒绝）。

请求参数：

| id | body | uuid | ✓ | 图谱 id |

#### POST /api/graph/delete

按 id 删除图谱，**级联删除其类型字典 / 实例 / 操作记录，不可逆**——删除对自动化（LLM）是高危操作，调用前必须确认影响面。
> graph 层例外：删除对象即图谱本身，无上层图谱作用域，因此允许一次跨图谱批量（`{ids: []}`），与其他层的 `graph_id + items[]` 约定不同。

请求参数：

| 字段 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| ids | body | uuid[] | ✓ | 图谱 id 列表（可一次删除多个图谱） |

响应参数：

| 字段 | 类型 | 说明 |
|---|---|---|
| ok | bool | 是否成功 |
| deleted | array | 删除 id |
| failed | array | 失败项 |

错误码：

| type | 说明 |
|---|---|
| 30001 | 图谱不存在 |

### 1.2 schema（结构操作）

属性类型（property）绑定到具体 object_type（该对象类型允许哪些属性键）；object / link 类型按 graph 分区。

### 1.3 instance（实例操作）

实例维度（dim）由调用方显式传入，本系统不做推断；所有端点 POST + body，graph_id 随请求体携带（实例 id 只在所属图谱内唯一）。查询 / 列表统一 `/object/list` 等（body 带 ids：空=全部，非空=指定 id，可与 type / dim / q / source / target 过滤组合）；节点 list 恒带 links 富化，传单 id 即详情（无独立详情端点）。批量写端点统一 `{graph_id, items[]}`，一次调用只操作一个图谱。

#### POST /api/instance/object/list
