# 设计文档 · 接口语义层次

> 按「操作语义」分四层：数据层 graph / schema / instance / transaction（对应数据模型四层）。
> **统一约定：无 query 参数，一律 POST + body 传参**（全端点 POST，无 GET）。
> 查询/列表统一 `.../list`：body 带 `ids`——**`ids` 空/省略 = 返回全部（list all），`ids` 非空 = 仅返回这些元素的信息**；过滤字段与 ids 组合（AND）；节点 list 恒带 links 富化，传单 id 即详情（无独立详情端点）。
> 批量写端点统一 `{graph_id, items[]}`——**一次调用只操作一个图谱**：graph_id 在顶层，其余字段均作为 items[] 的子项，items 恒为数组；非批量单对象端点仍为平铺字段。例外：`POST /api/graph/delete`（删除对象即图谱本身，允许跨图谱批量 `{ids}`）。身份与鉴权见 §5。

## 1. 分层总览

| 类型 | 层 | 名称 | 操作对象 | 职责 |
|---|---|---|---|---|
| 数据层 | graph | 图谱操作 | 用户图谱（graph）与图结构 | 图谱列表与元数据、指定深度概览、subgraphs / paths / neighbours、节点连通性、图谱统计 |
| 数据层 | schema | 结构操作 | Schema 元模型（类型字典） | 节点 / 关系 / 属性类型的增删改查（支持批量）；属性类型绑定对象类型；类型统计 |
| 数据层 | instance | 实例操作 | 实体实例（节点 / 关系 / 属性） | 实例的增删改查、按业务键合并、复合结构动作（插入 / 移除 / 挂接），写支持批量 |
| 数据层 | transaction | 事务操作 | 操作记录 | 每次写调用的操作记录（分页 / 排序），只读审计 |

## 2. 各层端点与职责

### graph（图谱操作）

数据层第一层，对应数据模型 graph 层（图谱 = graph）；统一 POST + body，graph_id 入 body。

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/graph/list` | POST | 图谱查询/列表（ids 空=当前用户全部图谱，非空=指定图谱元数据；list 即元数据） |
| `/api/graph/create` | POST | 创建图谱（name / description + dims 维度字典，dims 创建后不可改） |
| `/api/graph/update` | POST | 更新图谱（id + name / description 部分更新；dims 创建后不可修改） |
| `/api/graph/delete` | POST | 删除图谱（`{ids}` 跨图谱批量，级联清理类型字典 / 实例 / 操作记录，不可逆；高危；唯一例外约定） |
| `/api/graph/overview` | POST | 指定深度概览（graph_id 在 body） |
| `/api/graph/neighbours` | POST | 邻居查询 |
| `/api/graph/paths` | POST | 路径查询 |
| `/api/graph/subgraphs` | POST | 子图提取 |
| `/api/graph/connected` | POST | 节点连通性判断 |
| `/api/graph/stats` | POST | 图谱统计 |

### schema（结构操作）

定义节点 / 关系 / 属性类型，是类型合法性的唯一事实源；只操作类型定义，不触碰实例；删除受实例占用保护。
属性类型（property）绑定到具体 object_type（该对象类型允许哪些属性键）。查询/列表统一 `.../list`（ids 空=全部，非空=指定 id，可与 type / q / object_type_id 过滤组合），无独立详情端点。

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/schema/types` | POST | 类型字典全量（body: graph_id） |
| `/api/schema/stat` | POST | 类型统计 |
| `/api/schema/object/list` | POST | 对象类型查询/列表（ids 空=全部，非空=指定 id，可与 type / q 过滤） |
| `/api/schema/object/create` | POST | 批量创建对象类型（graph_id + items[]） |
| `/api/schema/object/update` | POST | 批量更新对象类型（graph_id + items[]，类型须属该图谱） |
| `/api/schema/object/delete` | POST | 批量删除对象类型（graph_id + items[] 类型 id） |
| `/api/schema/link/list` | POST | 关系类型查询/列表（ids 空=全部，非空=指定 id，可与 type / q 过滤） |
| `/api/schema/link/create` | POST | 批量创建关系类型（graph_id + items[]） |
| `/api/schema/link/update` | POST | 批量更新关系类型（graph_id + items[]，类型须属该图谱） |
| `/api/schema/link/delete` | POST | 批量删除关系类型（graph_id + items[] 类型 id） |
| `/api/schema/property/list` | POST | 属性类型查询/列表（ids 空=全部，非空=指定 id，可按 object_type_id / type / q 过滤） |
| `/api/schema/property/create` | POST | 批量创建属性类型（绑定 object_type，graph_id + items[]） |
| `/api/schema/property/update` | POST | 批量更新属性类型（graph_id + items[]，类型须属该图谱） |
| `/api/schema/property/delete` | POST | 批量删除属性类型（graph_id + items[] 类型 id） |

### instance（实例操作）

面向节点 / 关系 / 属性的读写；除单资源 CRUD 外，提供针对 o/l/p 的一次性复合结构动作（插入 / 移除 / 挂接），供图谱构建使用。
实例维度（dim）由调用方显式传入——本系统只做基础设施，不做 dim 推断。所有端点 POST + body；graph_id 随请求体携带（实例 id 只在所属图谱内唯一）。查询/列表统一 `.../list`（ids 空=全部，非空=指定 id，可与 type / dim / q / source / target 过滤组合）；节点 list 恒带 links 富化，传单 id 即详情。批量写端点统一 `{graph_id, items[]}`，一次调用只操作一个图谱。

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/instance/object/list` | POST | 节点查询/列表（ids 空=全部，非空=指定 id，可与 type / dim / q / limit 过滤；恒含 links） |
| `/api/instance/object/create` | POST | 批量创建节点（graph_id + items[]；携带 property 一并写入） |
| `/api/instance/object/update` | POST | 批量更新节点（graph_id + items[]） |
| `/api/instance/object/delete` | POST | 批量删除节点（graph_id + items[] 节点 id） |
| `/api/instance/object/insert` | POST | 链路插入节点（拆开一条 link，建立两条新 link） |
| `/api/instance/object/remove` | POST | 移除链中间节点并合并链路（仅允许恰有 1 入 + 1 出两条边，否则报错） |
| `/api/instance/object/attach` | POST | 已知 source 新增节点并连线 |
| `/api/instance/object/detach` | POST | 已知 source 删除节点及其边 |
| `/api/instance/link/list` | POST | 关系查询/列表（ids 空=全部，非空=指定 id，可与 type / source / target 过滤） |
| `/api/instance/link/create` | POST | 批量创建关系（graph_id + items[]） |
| `/api/instance/link/update` | POST | 批量更新关系（graph_id + items[]） |
| `/api/instance/link/delete` | POST | 批量删除关系（graph_id + items[] 关系 id） |
| `/api/instance/property/list` | POST | 对象属性查询（按 object_id / type，属性非 id 寻址） |
| `/api/instance/property/create` | POST | 添加对象属性（高危兜底） |
| `/api/instance/property/update` | POST | 更新对象属性（高危兜底） |
| `/api/instance/property/delete` | POST | 删除对象属性（高危兜底） |

### transaction（事务操作）

每次写调用落一条操作记录，供审计回溯；读调用不记录。

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/transaction/list` | POST | 操作记录列表（body: page / page_size / sort） |

## 3. 层间关系

```
数据层：graph（图谱）→ schema（约束）→ instance（实例数据）→ transaction（操作记录）   ← 对应数据模型四层
```

- 数据层四层对应数据模型四层：graph ↔ 图谱层、schema ↔ 结构层、instance ↔ 实例层、transaction ↔ 事务层。
- transaction 记录每次写调用，支撑审计与回溯。
- 读操作归各层只读侧：graph 读 = 列表 / 元数据 / 概览 / 结构查询，schema 读 = 类型字典 / 统计，instance 读 = 实例（list 恒含 links，单 id 即详情）。

## 4. 内置功能层（不暴露为接口）

校验（归属 / 类型 / 必填 / 维度键）、悬空引用拦截、操作记录内建于写入链路，作为功能层存在，不提供独立端点。归属校验基于 graph 表：`graph.user_id` 记录所属用户，操作前比对。

## 5. 接口鉴权（调用方身份注入）

本服务为**微服务**，不内置鉴权：不做登录、不校验凭证，身份由调用方（上游网关 / 其他服务 / 前端）随请求注入。

- **身份头 `X-Identity`**：值为 base64(JSON)。JSON 含字段：
  - `user_id`（必填，字符串）：操作归属用户，作为 graph / schema / instance 归属校验依据；
  - `agent_id`（可选，字符串）：发起调用的智能体，仅作审计 / 识别，不作鉴权依据。
- **缺失 / 非 base64 / 非 JSON / 缺 user_id** → 20001 未认证（HTTP 401）。
- **归属校验**：基于 graph 表 `graph.user_id` 比对调用方 `user_id`，不符 → 20002 无权（HTTP 403）。
- **服务端无任何默认身份**：调用方未注入即拒绝。dev 阶段由前端注入测试身份，生产由网关 / 上游服务注入真实身份。
