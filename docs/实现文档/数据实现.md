# 实现 · 数据

> 依据《数据库设计》。SQLite 单库承载全部数据（图谱 / 类型字典 / 操作记录 / 实例）。本页为建库与迁移实现。

## 1. SQLite DDL

幂等建表（`CREATE TABLE IF NOT EXISTS`），时间戳统一 `created_at` / `updated_at`（ISO 字符串）。

```sql
-- 图谱（user_id 记录归属，graph 操作校验；无 user 表）
CREATE TABLE IF NOT EXISTS graph (
    id          TEXT PRIMARY KEY,
    user_id     TEXT NOT NULL,
    name        TEXT NOT NULL,
    description TEXT NOT NULL DEFAULT '',
    dims        TEXT NOT NULL DEFAULT '[]',   -- json：结构化维度字典 [{key,label,values:[{code,label}]}]（创建后不可改）
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);

-- 类型字典三表，按 graph 分区
CREATE TABLE IF NOT EXISTS object_type (
    id          TEXT PRIMARY KEY,
    graph_id    TEXT NOT NULL,
    type        TEXT NOT NULL,
    name        TEXT NOT NULL,
    description TEXT,
    dim         TEXT NOT NULL DEFAULT '{}',
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL,
    UNIQUE (graph_id, type)
);

CREATE TABLE IF NOT EXISTS link_type (
    id          TEXT PRIMARY KEY,
    graph_id    TEXT NOT NULL,
    type        TEXT NOT NULL,
    name        TEXT NOT NULL,
    description TEXT,
    dim         TEXT NOT NULL DEFAULT '{}',  -- 声明 source/target 指向（取值），引擎不强制
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL,
    UNIQUE (graph_id, type)
);

-- property 绑定 object_type：该对象类型允许哪些属性键
CREATE TABLE IF NOT EXISTS property_type (
    id              TEXT PRIMARY KEY,
    graph_id        TEXT NOT NULL,
    object_type_id  TEXT NOT NULL,
    type            TEXT NOT NULL,
    name            TEXT NOT NULL,
    value_type      TEXT NOT NULL DEFAULT 'string',
    description     TEXT,
    dim             TEXT NOT NULL DEFAULT '{}',
    created_at      TEXT NOT NULL,
    updated_at      TEXT NOT NULL,
    UNIQUE (graph_id, object_type_id, type)
);

-- 操作记录（每次写调用一条，审计）
CREATE TABLE IF NOT EXISTS operation (
    id         TEXT PRIMARY KEY,
    graph_id   TEXT NOT NULL,
    user_id    TEXT NOT NULL,
    layer      TEXT NOT NULL,        -- graph / schema / instance
    action     TEXT NOT NULL,        -- resource.action
    payload    TEXT NOT NULL DEFAULT '{}',
    created_at TEXT NOT NULL
);

-- 节点实例
CREATE TABLE IF NOT EXISTS object (
    id            TEXT PRIMARY KEY,
    graph_id      TEXT NOT NULL,
    type          TEXT NOT NULL,
    title         TEXT NOT NULL,
    content       TEXT NOT NULL DEFAULT '',
    property      TEXT NOT NULL DEFAULT '{}',  -- json
    dim           TEXT NOT NULL DEFAULT '{}',  -- json
    business_key  TEXT,
    created_at    TEXT NOT NULL,
    updated_at    TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS ix_object_graph_type ON object (graph_id, type);
CREATE INDEX IF NOT EXISTS ix_object_graph_bkey ON object (graph_id, business_key);

-- 关系实例
CREATE TABLE IF NOT EXISTS link (
    id         TEXT PRIMARY KEY,
    graph_id   TEXT NOT NULL,
    type       TEXT NOT NULL,
    source     TEXT NOT NULL,
    target     TEXT NOT NULL,
    property   TEXT NOT NULL DEFAULT '{}',
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS ix_link_graph_type ON link (graph_id, type);
CREATE INDEX IF NOT EXISTS ix_link_graph_source ON link (graph_id, source);
CREATE INDEX IF NOT EXISTS ix_link_graph_target ON link (graph_id, target);
```

## 2. 迁移（Migration）

- **建库**：`CREATE TABLE IF NOT EXISTS` 幂等，重复启动不重建、不覆盖。
- **列演进**：追加列用 `ALTER TABLE ... ADD COLUMN`；改名 / 改约束写迁移脚本（建新表 → 拷贝 → 换名）。
- **不预置**：启动不灌入任何业务内容。图谱 / 维度字典 / 类型字典 / 实例均由应用层经写接口装配（基于 graph 表校验归属；`user_id` 记录归属用户）。

## 3. schema 演化

- **新增 property_type**：现有节点缺键视为空，无需迁移。
- **修改 property_type**：需重新调整所有受影响节点——扫描相关节点，重写 `property` Map。
- **删除 property_type**：从所有相关节点的 `property` 中移除该键。
- **类型改名（object_type.type / link_type.type）**：实例 `type` 列随之批量更新，属重写级操作。
